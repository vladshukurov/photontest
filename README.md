# Фотон — генератор световых фонов

Онлайн-версия: https://vladshukurov.github.io/photontest/

- `photon.html` — инструмент целиком, одним файлом (WebGL2, без зависимостей). Можно открыть и локально двойным кликом.
- `КАК ПОЛЬЗОВАТЬСЯ.txt` — инструкция.

Каждый пуш в `main` публикует сайт через GitHub Actions (`.github/workflows/pages.yml`).
